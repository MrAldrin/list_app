# Backlog

Lifecycle: tracked. Task status is in local Beads. This page is an entry point,
not a second queue. Plans keep scope, decisions, evidence and supporting detail.

<span id="current-focus"></span>

## Current focus

Use the [local task guide](../docs/beads.md) to select the one primary store and
read its task records. The guide explains path checks, source groups, claims
and native recovery. Native Ready and source placement do not approve work.
The owner selects work and changes to the agenda; existing
[scope gates](../docs/scope.md#gates) still apply.
